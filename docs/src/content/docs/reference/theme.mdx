Three globals hold what is shared. Set them once at start-up and every component follows. Each component still has its own property for the same thing, and that one wins.

```slint
init => {
    DitherTheme.background = #1b1a19;
    DitherTheme.foreground = #ebe5d9;
    DitherTheme.ink = #5471f5;
    DitherTheme.animated = false;
    DitherMotion.hover = DitherHover.spotlight;
}
```

Put this in the `init` callback of your window. [Theming](../../guides/theming/) shows it in context, and how to set the same thing from Rust.

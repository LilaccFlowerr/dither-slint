The face is drawn from the name you give it, so the same name always gives the same face and colour. That makes it a placeholder for people without a photo, and for teams, bots and projects. It is a 5 by 5 grid of blocks, mirrored left to right, on a lit dithered disc.

<Demo
	title="Faces"
	code={`DitherAvatar {
    name: "Ada Lovelace";
}

DitherAvatar {
    name: "Grace Hopper";
}

DitherAvatar {
    name: "Alan Turing";
}`}
>
	<Avatar name="Ada Lovelace" size={56} label="Ada Lovelace" />
	<Avatar name="Grace Hopper" size={56} label="Grace Hopper" />
	<Avatar name="Alan Turing" size={56} label="Alan Turing" />
	<Avatar name="Linus" size={56} label="Linus" />
	<Avatar name="dither-bot" size={56} label="dither-bot" />
</Demo>

## Examples

<Demo
	title="Fills, shape and ring"
	code={`DitherAvatar {
    name: "Ada Lovelace";
    fill: DitherFill.dotted;
}

DitherAvatar {
    name: "Ada Lovelace";
    fill: DitherFill.hatched;
}

DitherAvatar {
    name: "Ada Lovelace";
    shape: DitherAvatarShape.square;
    color: DitherPalette.orange;
}

DitherAvatar {
    name: "Ada Lovelace";
    ring: true;
    bloom: DitherBloom.high;
}`}
>
	<Avatar name="Ada Lovelace" size={56} fill="dotted" label="dotted" />
	<Avatar name="Ada Lovelace" size={56} fill="hatched" label="hatched" />
	<Avatar name="Ada Lovelace" size={56} shape="square" color="orange" label="square, orange" />
	<Avatar name="Ada Lovelace" size={56} ring bloom="high" label="ring and glow" />
</Demo>

<Demo
	title="Status and group"
	code={`DitherAvatar {
    name: "Grace Hopper";
    status: DitherAvatarStatus.online;
}

DitherAvatarGroup {
    names: ["Ada", "Grace", "Alan", "Linus", "Margaret", "Dennis"];
    max: 4;
}`}
>
	<Avatar name="Grace Hopper" size={48} status="online" label="online" />
	<Avatar name="Alan Turing" size={48} status="busy" label="busy" />
	<AvatarGroup names={['Ada', 'Grace', 'Alan', 'Linus', 'Margaret', 'Dennis']} max={4} size={40} />
</Demo>

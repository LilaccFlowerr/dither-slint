title: DitherCard
description: A card with a dithered glow in a corner or along an edge.
---

import Card from '../../../components/Card.astro';
import Demo from '../../../components/Demo.astro';
import Api from '../../../components/Api.astro';

The glow is a stack of nine rings, each filled with a denser dither than the one under it, so it reads as one smooth falloff. A dithered rim runs along the border and is densest near the glow. Put your content inside.

<Demo
	title="Glow"
	code={`DitherCard {
    glow: DitherGlow.top-left;
    Text { text: "Usage"; }
}

DitherCard {
    glow: DitherGlow.bottom-right;
    Text { text: "Pricing"; }
}

DitherCard {
    glow: DitherGlow.top;
    Text { text: "Docs"; }
}`}
>
	<Card title="Usage" glow="top-left">A dithered glow, a dithered rim.</Card>
	<Card title="Pricing" glow="bottom-right">A dithered glow, a dithered rim.</Card>
	<Card title="Docs" glow="top">A dithered glow, a dithered rim.</Card>
</Demo>

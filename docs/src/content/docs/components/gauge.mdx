---
title: DitherGauge
description: "A radial gauge built from dithered blocks: a half arc, a 270° dial or a full ring."
---

import Gauge from '../../../components/Gauge.astro';
import Demo from '../../../components/Demo.astro';
import Api from '../../../components/Api.astro';

Blocks up to the value fill in over a faint track. The block at the value is solid and steps out by a cell, like a needle, and with the gradient fill each block behind it is a step lighter. The blocks fade in one by one when the gauge appears.

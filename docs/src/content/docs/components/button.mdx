import Button from '../../../components/Button.astro';

A highlight is dithered down from the top and a shade is dithered up from the bottom. Hover brightens it and a press shades it from the top.

	title="Variants"
	code={`DitherButton {

    text: "View logs";
    variant: DitherButtonVariant.outline;
}`}
>
	<Button text="Deploy" />

</Demo>

## Properties

<Api file="button" />

Turn the motion off everywhere with `DitherTheme.animated = false`, or per button with `animated: false`. `DitherFx` is the layer behind it, so other components can use the same sweep and ripple.

title: DitherNumber
description: "An animated number for dashboards and landing stats: each changed digit rolls into place, faded at its edges by a dither."

import DitherNumber from '../../../components/DitherNumber.astro';
import Demo from '../../../components/Demo.astro';
import Api from '../../../components/Api.astro';

Each changed digit rolls on a strip to its new value, forward when the number goes up and backward when it goes down, and a digit that has to pass more than ten spins an extra lap. Digits start one after another from the left and take the accent colour while they move. The top and bottom of each digit fade out in a dither. The number rolls in from `from` when it appears, and again whenever `value` changes. Click the large one to add 1,337.

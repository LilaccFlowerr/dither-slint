Letters take a dither in any colour: a gradient that thins out in one direction, drifting noise, dots or hatching. The fill moves slowly. Set `fill: solid` for plain text.

Slint cannot clip a picture to the shape of letters, so the dither is drawn as a layer over the text that hides the cells that should be empty. This works on a flat background: set `backdrop` to the colour behind the text, which is the theme background by default.

A skeleton stands in for content that is still loading. At rest each block is a faint tint under a dither ramp that thins out from the left edge, so it reads as dither even in a still frame. `sweep` runs a band of denser dither across it, and `pulse` steps the whole block up through three dither levels and back down. It is hidden from assistive technology, so announce what is loading in words.

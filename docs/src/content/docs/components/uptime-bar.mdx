One bar per day, oldest first. The status shows in colour and in texture, so it never relies on colour alone: up days are a gradient that is dense at the base, degraded days hatched, outages solid and days without data dotted. Hover, tap or arrow through the bars for each day's details. The row shows the last 30, 60 or 90 days, depending on its width.

## Properties

| Property | Default | |
| --- | --- | --- |
| `label` | | The service, such as "API". |
| `days` | | One entry per day, oldest first. Each has a `date` (`"2026-10-13"`), an `uptime` from 0 to 1 (negative for no data) and an optional `note` for the tooltip. |
| `fill` | `gradient` | Texture of the up days. Degraded days are always hatched, outages solid and days without data dotted. |
| `bloom` | `off` | `low` or `high` adds a glow behind degraded days and outages, so incidents stand out. |
| `up-color` | `DitherPalette.green` | Colour of the up days. |
| `degraded-color` | `DitherPalette.orange` | Colour of the degraded days. |
| `down-color` | `DitherPalette.red` | Colour of the outages. |
| `none-color` | `DitherPalette.grey` | Colour of the days without data. |
| `matrix` | `bayer4` | The dither pattern. |
| `cell` | `2px` | Size of one dither cell. |

A day is up at 99.9% or more, degraded at 99% or more and an outage below that. Set `status` with `custom-status: true` to decide it yourself. The uptime in the header is the average of the days with data, and percentages are rounded down, so 99.999% never reads as 100%.

Every component is a `Dither…` element you place in a `.slint` file. They share the same conventions: the colours and the motion come from the [theme](../reference/theme/), `cell` sets the size of one dither dot, and `animated` turns the motion off. Each page has a live demo, examples you can copy, and every property listed, with the types linked to the [type reference](../reference/types/).

Looking for the animated backgrounds, such as aurora or plasma? They are under [Backgrounds](../backgrounds/overview/).

import Demo from '../../../components/Demo.astro';

Each bar is a dithered body under a solid cap. With the default `gradient` fill a bar is densest at its top and thins out towards the axis. The highlighted bar, or the one under the pointer, fills in solid. Several series sit side by side, stack on top of each other, or stack and scale to 100%.

## Data

The data is the same as for [DitherLineChart](../line-chart/): `categories` and `series`, each with `values`. The `low`, `high` and `dashed` fields are not used; leave them empty. A transparent `color` takes the next colour of the series.

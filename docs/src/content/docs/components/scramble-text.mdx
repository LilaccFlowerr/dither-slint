---
title: DitherScrambleText
description: "A decode effect with no layout shift: each character resolves from a dithered block through a few glyphs to its letter."
---

import Demo from '../../../components/Demo.astro';
import TextEffect from '../../../components/TextEffect.astro';
import Api from '../../../components/Api.astro';

Each character resolves on its own, slightly staggered. A dithered block thickens through the dither levels, a few glyphs flicker, and the letter settles, fading from the ink colour to the text colour. Changing `text` scrambles only the characters that differ, from the old text to the new one. Every slot keeps the width of its final letter, so nothing shifts.

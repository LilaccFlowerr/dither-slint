import Input from '../../../components/Input.astro';
import Demo from '../../../components/Demo.astro';
import Api from '../../../components/Api.astro';

The field is drawn like the outline button: a faint tint of the colour inside a hairline, with a dithered floor that rises from the bottom edge. Hover thickens the floor a little. Focus fades in a denser, taller floor and turns the hairline to the colour. Only opacity animates, so every dot stays on the grid.

## Properties

<Api file="dither-input" />

`edited(string)` is called whenever the text changes, `accepted(string)` when you press Enter and `cleared()` after the clear button or Escape.

```slint
DitherInput {
    edited(text) => {
        debug(text);
    }
}
```

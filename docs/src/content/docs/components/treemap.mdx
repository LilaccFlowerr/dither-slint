Each item is a tile, sized by its value in a squarified treemap. Use it for anything that adds up to a whole: headcount by team, revenue by region, disk space, the parts of a context window. When it appears the values grow in one after another. Hover a tile to dim the others and see its share.

<Demo
	title="Basic"
	code={`DitherTreemap {
    title: "Headcount by team";
    unit: " people";
    status: "Hover a team for its share.";
    items: [
        { label: "Engineering", value: 48, color: DitherPalette.blue, fill: DitherFill.gradient, detail: "Platform and product" },
        { label: "Sales", value: 32, color: DitherPalette.purple, fill: DitherFill.gradient, detail: "Direct and partners" },
        { label: "Marketing", value: 20, color: DitherPalette.green, fill: DitherFill.gradient, detail: "Brand and growth" },
    ];
}`}
>
	<Treemap title="Headcount by team" unit=" people" status="Hover a team for its share." />
</Demo>

## A remainder

Mark one item as the `remainder` and it takes the space that is left of the `capacity`, on the right. It is hatched, and it shrinks while the other values grow in. This suits a disk with free space, a budget with money left, or a context window with room to spare.

<Demo
	title="Storage"
	code={`DitherTreemap {

        { label: "Free", value: 208, color: DitherPalette.grey, fill: DitherFill.hatched, detail: "Available space", remainder: true },

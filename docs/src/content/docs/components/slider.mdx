---
title: DitherSlider
description: A range slider whose fill thins out into dither behind the thumb, supporting both notched thumb and direct bar drag variants.
---

import Slider from '../../../components/Slider.astro';
import Demo from '../../../components/Demo.astro';

The filled part of the track is a dither ramp worked out cell by cell: sparse far from the thumb, denser towards it, and solid for the last two cells before a one-cell gap at the thumb. Hover, keyboard focus and drag fade in a longer, denser ramp.

The slider supports two distinct variants:
- **`thumb`** (default): An upstream notched cap lit like the button with highlights, shade bevels, and a central grip line.
- **`bar`**: A seamless draggable progress-bar slider with a 1-cell leading edge cap and optional segment breaks.

## Properties

| Property | Default | |
| --- | --- | --- |
| `value` | `0` | The current value. |
| `minimum` | `0` | Lowest value. |
| `maximum` | `100` | Highest value. |
| `step` | `1` | The value snaps to multiples of this from `minimum`. `0` is smooth. |
| `variant` | `thumb` | `thumb` for notched lit thumb; `bar` for seamless draggable meter bar. |
| `fill` | `gradient` | `gradient` (Bayer ramp), `dotted`, `hatched` or `solid`. |
| `segments` | `0` | When > 1, divides the track into discrete blocks with 1-cell gaps. |
| `ticks` | `false` | When true, renders step tick marks under the track lit within active range. |
| `label` | `""` | Label text displayed above the track. |
| `unit` | `""` | Unit suffix displayed beside the readout (e.g. `"%"` or `" dB"`). |
| `show-value`| `true` | Shows live numeric readout next to the label. |
| `show-range`| `false`| Shows `minimum` and `maximum` values under the track edges. |
| `color` | `DitherTheme.ink` | Colour of the fill and the thumb. |
| `size` | `md` | `sm`, `md` or `lg`: tracks of 6, 8 and 12 pixels with thumbs 20, 24 and 30 pixels tall. |
| `bloom` | `off` | `low` or `high` adds a glow in the slider's colour. |
| `matrix` | `bayer4` | The dither pattern of the fill. |
| `cell` | `2px` | Size of one dither cell. |
| `enabled` | `true` | Drops to 45% opacity and ignores the pointer and keys when `false`. |

`changed(float)` is called with the new value whenever you move it. Arrow keys, Page Up/Down, Home and End are supported for keyboard navigation.

```slint
DitherSlider {
    changed(value) => {
        debug(value);
    }
}
```

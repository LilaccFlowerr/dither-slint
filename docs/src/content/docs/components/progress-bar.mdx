With a `value` the fill grows to it, densest at its leading edge and capped with one solid cell so the value reads exactly, even in the sparse textures. Without a value a dithered comet sweeps the track. `parts` stacks several values side by side, each in its own colour, with a legend. `segments` cuts the bar into blocks, like a step meter.

## Properties

<Api file="dither-progress-bar" />

Parts that add up to more than `maximum` are cut off at the end of the bar. Without a `color` a part takes the next colour of the series: ink, orange, green, pink, purple, blue, red and grey.

The segments are cut with a stripe in the `gap` colour, so set it to the colour the bar sits on when that is not the page background.

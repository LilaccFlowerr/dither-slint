Every square is a block of 4×4 dither cells with one cell of gap, so its density steps cleanly from dots to a checkerboard, a hollow frame and solid. Hover a square for its value and use the legend to spotlight one density. When the width runs out the grid shrinks its cells, down to 2 px, and then drops the oldest columns.

## Data

In `calendar` mode `entries` is a list of `{ date, value }` with dates as `YYYY-MM-DD`. Several entries for one day add up, and days without an entry count as 0. The chart ends with the latest day and shows `weeks` columns, one per week.

In `matrix` mode `grid` holds one `{ values }` per row, with `rows` and `columns` as the labels. A missing value draws nothing.

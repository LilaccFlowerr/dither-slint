Two beams of light that fan down from above the box and flicker. Pick a `preset` (`cyber-blue`, `azure-and-white`, `sunset-rose`, `emerald-aurora`, `neon-violet`, `solar-flare` or `monochrome`); every other property starts at the preset's value and overrides it when you set it. The demo shows Cyber Blue; give the second colour its own value to see two beams.

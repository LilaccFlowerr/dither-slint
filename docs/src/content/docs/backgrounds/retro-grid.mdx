A perspective grid floor scrolling towards a horizon under a striped, glowing sun, as on an eighties record sleeve.

| Property | Default | |
| --- | --- | --- |
| `horizon` | `0.42` | Height of the horizon, 0 (bottom) to 1 (top). |
| `sun` | `0.4` | Size of the sun, as a share of the box height. 0 hides it. |
| `columns` | `12` | How many grid squares across the front of the floor in a 16:10 box. Narrower boxes show fewer. |

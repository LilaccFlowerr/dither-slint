A night sky of dithered stars in three parallax layers that twinkle and drift slowly. Each square of a layer's grid holds at most one star, so stars never clump, and a star's brightness snaps to a whole palette colour, so it never flickers between dither thresholds as it drifts. The brightest get a small cross.

| Property | Default | |
| --- | --- | --- |
| `density` | `1` | How many stars, 0 to 2. |
| `twinkle` | `0.6` | How much each star pulses, 0 (steady) to 1. |
| `angle` | `270` | Direction the stars drift, in degrees as in CSS: 0 is up, 90 right. |
| `drift` | `1.6` | Drift speed of the nearest layer, in cells per second. 0 holds them still. |
| `nebula` | `0.5` | Strength of a faint dithered haze behind the stars, 0 to 1. |

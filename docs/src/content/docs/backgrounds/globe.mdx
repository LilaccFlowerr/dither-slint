A rotating dithered globe: land from a built-in mask, a lit terminator and a thin atmosphere, with pulsing markers and arcs between places. Drag it sideways to spin it and up or down to tilt it, or press the arrow keys while it has focus. A quick flick keeps turning and slows down, and the idle spin comes back afterwards. The globe stays round and centred in its box.

```slint
DitherGlobe {
    markers: [{ lat: 48.9, lon: 2.3 }, { lat: 40.7, lon: -74 }];
    arcs: [{ from-lat: 48.9, from-lon: 2.3, to-lat: 40.7, to-lon: -74 }];
}
```

| Property | Default | |
| --- | --- | --- |
| `color` | `DitherTheme.ink` | Colour of the land and the atmosphere. |
| `accent` | `DitherPalette.orange` | Colour of markers and arcs unless they set their own. |
| `markers` | none | Places to mark, each with `lat`, `lon` (degrees, north and east positive) and an optional `color`. Markers on the far side are hidden. |
| `arcs` | none | Lines lifted off the surface, each with `from-lat`, `from-lon`, `to-lat`, `to-lon` and an optional `color`. |
| `speed` | `6` | Degrees of rotation per second. Negative spins the other way. |
| `start` | `10` | The longitude facing the viewer at the start. |
| `tilt` | `18` | How far the north pole leans towards the viewer, in degrees. |
| `light` | `300` | Where the light comes from, in degrees clockwise from the top. 300 is the upper left. |
| `ocean` | `0.18` | Brightness of the sea on the lit side, 0 to 1. |
| `atmosphere` | `true` | A thin dithered glow around the lit rim. |
| `draggable` | `true` | Let people drag or use the arrow keys to turn the globe. |
| `cell` | `2px` | Size of one dither cell. |
| `matrix` | `bayer4` | The dither pattern. |
| `animated` | `DitherTheme.animated` | Spin and pulse. `false` draws one still frame. |

The land comes from [Natural Earth](https://www.naturalearthdata.com) (public domain), stored as a 3.8 KB mask in the crate. Nothing is fetched.

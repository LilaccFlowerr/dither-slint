A background is a *field*: a function that returns a tone for every cell. The engine turns the tones into dots, picks the colours from your palette and animates the time. Put one in any box:

```slint
Rectangle {
    clip: true;
    DitherRipples { }
}
```

All of them share these properties:

| Property | Default | |
| --- | --- | --- |
| `palette` | depends | Two or more colours, from paper to ink. |
| `matrix` | `bayer4` | The dither pattern. |
| `cell` | `3px` | Size of one dither cell. |
| `speed` | `1` | Time multiplier. |
| `still-time` | depends | The moment shown when `animated` is `false`. |
| `animated` | `DitherTheme.animated` | |

The backgrounds are drawn on the CPU. A 1440 by 700 box with 3px cells is 480 by 234 cells and takes a few milliseconds per frame in a release build. Run in release, or set `opt-level = 3` for your dependencies.

A slow, swirling three-colour gradient. Pick a `preset` (`prism`, `lava`, `plasma`, `pulse`, `vortex` or `mist`); every other property starts at the preset's value and overrides it when you set it. The demo shows Prism.

| Property | Default | |
| --- | --- | --- |
| `preset` | `prism` | Starting values for everything below. |
| `color1`, `color2`, `color3` | from the preset | The three colours. The palette runs from `color1` through `color2` to `color3`, with a blend between each pair. |
| `rotation` | from the preset | Angle of the pattern, in degrees. |
| `proportion` | from the preset | Balance between the colours, 0 to 100. |
| `scale` | from the preset | Size of the pattern, 0 to 1. |
| `speed` | from the preset | How fast it swirls, 0 to 100. |
| `distortion` | from the preset | Noise that bends the pattern, 0 to 100. |
| `swirl` | from the preset | Strength of the swirl, 0 to 100. |
| `swirl-iterations` | from the preset | How many times it swirls, 1 to 30. |
| `softness` | from the preset | Soft or sharp edges between the colours, 0 to 100. |
| `offset` | from the preset | Where in its loop it starts. |
| `shape` | from the preset | The pattern the swirl folds: `checks`, `stripes` or `edge`. |
| `shape-size` | from the preset | Size of that pattern, 0 to 100. |

Curtains of light that fold, sway and shimmer. Set `color`, `tip-color` and `background` for a quick palette, or pass `palette` from paper to brightest to take over.

| Property | Default | |
| --- | --- | --- |
| `color` | `DitherTheme.ink` | The bright lower edge of each curtain. |
| `tip-color` | `color` | The faint tops of the rays, for a two-tone sky. |
| `background` | `DitherTheme.background` | The sky behind. |
| `curtains` | `3` | Number of curtains, 1 to 6. |
| `edge-height` | `0.42` | Where the lowest bright edge hangs, 0 (bottom) to 1 (top). |
| `spread` | `0.11` | Vertical gap between curtains. |
| `sway` | `1` | How far the edges fold, 0 to 3. |
| `turbulence` | `0.6` | Fine ripples along the edges, 0 to 2. |
| `rays` | `8` | How many rays fit across, 2 to 20. |
| `length` | `0.45` | How far the rays reach, 0 to 1. |
| `glow` | `0.9` | Brightness of the edge line, 0 to 2. |
| `intensity` | `0.95` | Brightness of the curtains, 0 to 1. |
| `shimmer` | `0.2` | Slow brightness ripple, 0 to 1. |
| `scale` | `1` | Horizontal zoom: higher fits more folds across. |
| `tilt` | `0` | Tilt in degrees, -45 to 45. |
| `drift` | `0` | Sideways travel, -2 (left) to 2 (right). |
| `direction` | `up` | `up`: rays rise from a bright lower edge. `down`: they hang from the top. |
| `mask` | `none` | Fade it out where text sits: `none`, `top`, `bottom` or `edges`. |

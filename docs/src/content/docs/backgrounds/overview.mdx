A background is a *field*: a function that returns a tone for every cell. The engine turns the tones into dots, picks the colours from your palette and animates the time. Put one in any box:

```slint
Rectangle {
    clip: true;
    DitherRipples { }
}
```

All of them share these properties:

| Property | Default | |
| --- | --- | --- |
| `palette` | depends | Two or more colours, from paper to ink. |
| `matrix` | `bayer4` | The dither pattern. |
| `cell` | `3px` | Size of one dither cell. |
| `speed` | `1` | Time multiplier. |
| `still-time` | depends | The moment shown when `animated` is `false`. |
| `animated` | `DitherTheme.animated` | |

The backgrounds are drawn on the CPU. A 1440 by 700 box with 3px cells is 480 by 234 cells and takes a few milliseconds per frame in a release build. Run in release, or set `opt-level = 3` for your dependencies.

---
title: Motion
description: "How the hover, press and idle effects work, and how to set them for one component or the whole app."
---

Every dither component can move, and the movement is drawn in the same dots as the rest. There are three kinds of effect, one for each moment:

| Kind | Plays when | Examples |
| --- | --- | --- |
| **Hover** | The pointer comes in, or the component gets keyboard focus. | A sweep across the box, a spotlight that follows the pointer. |
| **Press** | The pointer goes down. | A ring that grows from where you pressed, sparks, a glitch. |
| **Idle** | Nothing is happening. | A slow shimmer, a glow that breathes, twinkling stars. |

You pick one effect of each kind, or `none`. The [Effects](../effects/) page plays every one of them.

## Which components have it

`DitherButton`, `DitherBadge`, `DitherCard` and `DitherInput` play these effects. They have a property for each kind:

| Component | `hover-effect` | `press-effect` | `idle-effect` |
| --- | :---: | :---: | :---: |
| `DitherButton` | yes | yes | yes |
| `DitherBadge` | yes | yes | yes |
| `DitherCard` | yes | yes | yes |
| `DitherInput` | yes | yes | no |

For your own components, [`DitherFx`](../dither-fx/) is the layer these four use, and you can put it inside any box. [Build your own](../build-your-own/) shows how.

## For one component

Set the effects on the component:

```slint
DitherButton {
    text: "Deploy";
    hover-effect: DitherHover.trace;
    press-effect: DitherPress.glitch;
    idle-effect: DitherIdle.shimmer;
}
```

To switch one kind off, use `none`, for example `hover-effect: DitherHover.none`.

## For the whole app

`DitherMotion` is a global with the default of every component. Set it once, in the `init` callback of your window:

```slint
export component AppWindow inherits Window {
    init => {
        DitherMotion.hover = DitherHover.spotlight;
        DitherMotion.press = DitherPress.burst;
        DitherMotion.idle = DitherIdle.breathe;
    }
}
```

A property on a component beats the global, so you can set a default and still give one button something else. The [Theming](../../guides/theming/) page shows how to set the same thing from Rust.

## Speed, intensity and matrix

Three more settings on `DitherMotion` shape how every effect looks:

| Setting | Does | Default |
| --- | --- | --- |
| `speed` | How fast the effects play. 2 is twice as fast, 0.5 half. | 1 |
| `intensity` | How bright the dots are, from 0 (invisible) to 1. | 1 |
| `matrix` | The [dither pattern](../../engine/matrices/) of the effects. | `bayer4` |

```slint
init => {
    DitherMotion.speed = 1.5;
    DitherMotion.intensity = 0.8;
    DitherMotion.matrix = DitherMatrix.bayer8;
}
```

The sliders on the [Effects](../effects/) page show what each of them does.

## Turning it off

`DitherTheme.animated = false` stills every component, including all of the effects. This is the one switch for a reduced-motion setting. Each of the four components has its own `animated` property that follows the global, so one of them can still choose `animated: true`.

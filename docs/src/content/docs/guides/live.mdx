This is the real gallery, compiled to WebAssembly. Hover over things, press them and open the pages in the sidebar.

<iframe
  src="/live/index.html"

  style="width: 100%; height: 640px; border: 1px solid var(--sl-color-gray-5); border-radius: 8px;"
></iframe>

The dithering runs on the CPU in a single thread here, so heavy pages such as Backgrounds can feel slow in a browser without a graphics card. A native app is much faster.

You can build it yourself from the repository root:

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli
web/build.sh
```
